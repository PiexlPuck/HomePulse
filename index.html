ℹ️ Gateway & Repeater Mode Details

HomePulse supports two modes of upstream gateway operations:

1. Database-backed Gateway Mode

Maintains a local database pool. Telemetry history is temporarily logged in Postgres, and active alarm triggers loop internally. API Keys verify authentication requests. Upstream forwarding copies telemetry immediately to target custom webhooks.

2. Stateless (DB-less) Repeater Mode

Deactivates all local database logging. Telemetry logs table writes are bypassed completely, transforming the gateway into a read-and-forward repeater. Safe for flash disk systems (like Raspberry Pi/eMMC) to prevent memory wearing. Uses the local master Preshared pairing PIN for query authentication.

*Note: Enabling Gateway mode suspends processor-heavy built-in background check tasks (monitors prober, statistics tracker, alerts validator) to conserve energy and network cycles.
